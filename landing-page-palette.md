# Landing page palette — black & blue (Vanguard-inspired)

Proposed for the TCS landing/marketing page (name, what TCS is, how it works — scroll narrative with card-flip animation). Distinct from the app UI's current purple/lavender palette; see [PRODUCT.md](PRODUCT.md) and [tcs-home-design.html](tcs-home-design.html).

Reference: real Cardfight!! Vanguard card back (black card, cyan/blue circuit glow, white border).

| Swatch | Hex | Role |
|---|---|---|
| Card black | `#0A0C10` | Base / page background |
| Panel | `#12161D` | Cards / sections, one step up from base |
| Vanguard blue | `#2F8FE8` | Primary accent (CTAs, key lines, active states) |
| Circuit cyan | `#5FD4FF` | Glow / highlight (card-flip trails, hover, emphasis text) |
| Card white | `#F4F5F7` | Headline text on black |
| Steel border | `#8C93A3` | Card frame / dividers / secondary text |

## Usage notes

- Base surfaces stay near-black (`#0A0C10` / `#12161D`); avoid pure `#000` so panels can separate from the page.
- Vanguard blue is the primary interactive accent; circuit cyan is reserved for glow/motion moments (card flip, scroll-triggered highlights), not everyday UI text, so it stays special.
- Body copy on black uses card white; steel border doubles as secondary/muted text.
- This palette is scoped to the landing page only — the marketplace app UI keeps its existing palette.
